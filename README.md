## 👨‍💻 How I Work

I like taking ownership of problems rather than just completing tickets.

**Understand → Design → Build → Test → Deploy → Monitor → Improve**

When something doesn't work, my first instinct isn't:

> "Let's restart the server."

It's:

> **"Why did this happen?"** 🤔

Because fixing the symptom is nice.

**Fixing the actual problem is better.**
